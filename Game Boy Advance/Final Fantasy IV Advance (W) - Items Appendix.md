# *Final Fantasy IV Advance* (W) - Items Value Appendix
All of the RAM values observed in *Final Fantasy IV Advance* (Game Boy Advance, World).

All values are **16-bit** unless otherwise noted.<br>Values are listed in **human-readable order**. In memory, multi-byte values are stored in **little-endian** format.

Example:
> Document Value: `$0121 - Asura's Rod`<br>RAM Value: `$2101 - Asura's Rod`

## Values
### Empty Values
```
$0000 - Empty                   $0060 - None
```

### Notes
- Values between `$00FC` and `$0144` are GBA / PSP-exclusive items.
- Dummied-out items include:
  - "Assassin Dagger" (`$0031`)
  - "Hand Axe" (`$0038`)
  - "None" (`$0046`)
    - This is an unusable duplicate of "Ragnarok" (`$003F`), but two-handed.
  - "None" (`$0060`)
    - Different from above.
  - "Muddy Water" (`$0136`)
  - "Raggedy Doll" (`$0140`)
